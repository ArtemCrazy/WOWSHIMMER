Два варианта структуры главной страницы

Это lo-fi прототипы-скетчи главной страницы многостраничного сайта. Модель проекта: публичная витрина бренда + закрытый партнёрский слой. Каталог открыт для всех с розничными ценами; партнёр после авторизации видит оптовые цены и собирает заявку. Розничные покупки уходят на маркетплейсы (Ozon, WB). Hero у обоих вариантов общий — имиджевое фото/видео + логотип. Разница в том, как раскрывается каталог: «Категории-якорь» ведёт через 4 типа украшений (Серьги · Подвески · Браслеты · Пусеты) — подходит, если у бренда есть структура. «Бренд-витрина» показывает товары напрямую плюс развёрнутую брендовую главную (палитра, «где купить», партнёрский блок, контакты) — подходит для небольшого ясного ассортимента.

Что общего

Многостраничный сайт · sitemap-полоска сверху · общий имиджевый hero · меню в шапке/футере ведёт на отдельные страницы · адаптив на мобильные

Чем отличаются

Первый блок под имиджем и порядок смысловых разделов — три разные «двери» для партнёра

Что дальше

Выбираем направление → карточка товара и ЛК → дизайн в монохромной палитре + shimmer-акцент

📝 Что важно держать в уме при просмотре

  • Модель сайта: публичная витрина бренда + закрытый партнёрский слой. Каталог открыт всем с розничными ценами; партнёр после авторизации видит оптовые цены и собирает заявку (она уходит менеджеру на e-mail). Розничные покупки физлиц — через маркетплейсы Ozon/Wildberries, не через сайт.
  • Без онлайн-оплаты, без корзины физлица. Оптовый доступ — только после ручного одобрения менеджером, не по самостоятельной регистрации.
  • Это прототип-скетч ГЛАВНОЙ страницы. Каталог, Карточка товара, О бренде, Контакты, ЛК — отдельные URL (заглушки в шапке/футере и sitemap-полоске сверху). Клик по любому пункту выдаёт алерт.
  • На главной живёт только содержимое по ТЗ: презентация бренда + условия сотрудничества + форма запроса на партнёрство. Плюс якорь варианта (палитра / витрина / форма+цифры).
  • Hero общий: тёмный имиджевый кадр (по референсу клиента — большое фото/видео), поверх — логотип, заголовок, 3 CTA («Смотреть каталог» / «Войти в ЛК» / «Стать партнёром»). В V3 первая CTA — «Стать партнёром». В прототипе вместо реального фото абстрактный SVG-баннер с силуэтами украшений.
  • Эстетика hero — из референса клиента (тёмный фон, бренд по центру), но без розничных «КУПИТЬ / СКИДКИ» — у нас B2B-оформление заявки, не кнопка покупки.
  • Шрифт Caveat и «бумажная» палитра — нарочно, чтобы не цепляться за стиль. Финальный сайт — минималистичный, монохромная гамма + shimmer-акцент по брифу.
  • Жёлтые подписи — заметки для нас и клиента, на финале их не будет. Адаптив — 980 / 720 / 420 px.
